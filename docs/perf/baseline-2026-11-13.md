## 4. Indexing on staging

| Mechanism | Staging | Live site today |
|---|---|---|
| `blog_public` | **0** (Settings → Reading → "Discourage") | — |
| `<meta name='robots'>` | **`noindex, nofollow`** (core, from `blog_public=0`) | `max-image-preview:large` |
| `robots.txt` | virtual, `Disallow: /wp-admin/` only, **no Sitemap line** | same + `Sitemap: https://trailseries.bg/wp-sitemap.xml` |
| `X-Robots-Tag` header | none | none |
| `.htaccess` rules | none for robots | — |
| Physical `robots.txt` | none | — |

So staging is blocked by the meta tag only: images, PDFs and other
non-HTML files are not covered, and `blog_public=0` travels with the
database copy to production (CUTOVER C7 flips it). The home page has no
canonical link (`show_on_front=posts`, so core treats `/` as the blog index).

## 5. Headers seen (all pages)

`Strict-Transport-Security`, `X-Frame-Options`, `Cross-Origin-Opener-Policy`.
