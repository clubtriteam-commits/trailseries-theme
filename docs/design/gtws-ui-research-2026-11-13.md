# UI/UX проучване: Golden Trail World Series → насоки за trailseries.bg

Дата: 2026-11-13. Метод: петте страници са заредени в истински Chrome (1440 px и 390 px),
със снимки на цялата страница и измерени computed стилове (шрифтове, цветове, grid-ове, радиуси).
Стойностите по-долу са измерени, не оценени на око.

## Три корекции на заданието

Заданието предполага елементи, които на сайта **не съществуват** (към датата на проучването):

1. **Няма подиум модул в класирането.** Топ 3 са обикновени редове; акцентът е само голямата
   оранжева цифра на мястото. Подиумът с три карти на `/klasiraniya/` при нас вече е повече от
   това, което има GTWS.
2. **Няма хронология/timeline на About.** Страницата е редуване „снимка + текст“ и една
   секция с текст върху снимка. Няма години, линия или scroll анимация на линия.
3. **Няма вълна/крива в hero.** Формата е снимка със **заоблени долни ъгли**
   (`border-radius: 0 0 64px 64px` + `overflow: hidden`). Без SVG path и без clip-path.

И едно за нашата страна: trailseries.bg не е на Astra/Elementor. Шаблоните са собствени PHP
файлове в `exhibz-child` със собствен CSS, така че всичко долу се прави с CSS в темата, без
page builder.

## Обща система (важи за всички страници)

| Елемент | Измерено на GTWS |
|---|---|
| Заглавия | Ubuntu 700; h1 48 px (60 px на вътрешните страници), секционно h2 48 px, на телефон 28 px |
| Основен текст | Geist 400, 16/24 px; навигация 14 px / 600 |
| Цветове | текст `#0F0F0F`; фон `#FAFAFA`; бели карти `#FFFFFF`; вторичен текст `#595959`; линии `#D9D9D9`; акцент `#F9AE00` (тъмен вариант `#C38A03`) |
| Контейнер | max-width 1664 px, странично поле 32 px (16 px на телефон) |
| Радиуси | hero 64 px долу; карти, бутони и табове 18 px; малки етикети 16–18 px |
| Бутони | „хапче“: черен фон + бял текст (основен), акцентен фон (CTA), контур 1 px акцент (вторичен); вътре стрелка в кръгче |
| Ритъм | празни блокове от 150–190 px между секциите (на телефон около 80 px) |
| Движение | преходи 0,3 s `cubic-bezier(0.4, 0, 0.2, 1)`; леко появяване на блоковете при scroll (`block-reveal`) |
| Хедър | прозрачен, абсолютно позициониран върху hero снимката, 88 px |
| Секционно заглавие | малка икона (глобус в акцентния цвят) + h2, подравнено вляво |

Сайтът е WordPress със собствени блокове и Tailwind. Няма тежки библиотеки за анимация.

**Какво да вземем:** един акцентен цвят върху почти черно-бяла основа, големите радиуси,
бутоните „хапче“, щедрия въздух между секциите.
**Какво да не копираме:** златния цвят, логото, глобуса и снимките. Това е идентичността на
GTWS. При нас акцентът остава синьото `#00AADD` (и оранжевото за CTA), шрифтовете остават
Raleway + Roboto (вече са self-hosted и имат кирилица).
**Внимание за контраст:** `#F9AE00` върху бяло не стига 4,5:1. GTWS го ползва почти само за
големи цифри и фонове. Същото важи за нашето синьо (одит L19): акцентът е за големи елементи и
фонове, не за дребен текст.

## 1. About

**Структура (отгоре надолу):**
1. Hero 450 px: снимка, тъмен слой (черно 60%), долу вляво малък надпис (24 px), h1 60 px и
   подзаглавие. Заоблени долни ъгли 64 px.
2. Блок „текст + снимка“: 12-колонен grid, gap 48 px, текст 5 колони, снимка 7 колони.
   Снимката е със съотношение ~4:3, `object-fit: cover`, радиус 18 px. Над текста стои лого.
3. Секция на цяла ширина: снимка за фон, тъмен слой, бяло h2 36 px + абзац, ограничени до
   ~830 px ширина, подравнени вляво.
4. Още три блока „снимка + текст“, като страните се **редуват** (`order` в grid-а).
5. Бюлетин и лента с партньори (общ футър за всички страници).

На телефон всичко става една колона: текстът над снимката, gap 48 px.

**CSS подход:**
```css
.tsr-story { display: grid; grid-template-columns: repeat(12, 1fr); gap: 3rem; align-items: center; }
.tsr-story__text  { grid-column: span 5; }
.tsr-story__media { grid-column: span 7; }
.tsr-story--flip .tsr-story__text { order: 2; }
.tsr-story__media img { width: 100%; aspect-ratio: 4 / 3; object-fit: cover; border-radius: 18px; }
@media (max-width: 1024px) { .tsr-story { grid-template-columns: 1fr; } .tsr-story > * { grid-column: auto; order: 0; } }
```

**1:1:** редуването 5/7, заоблените снимки, секцията с текст върху снимка.
**Адаптация за `/istoriya/`:** тук хронологията има смисъл, макар GTWS да няма такава. 14
сезона = 14 кратки блока или по-добре 4–5 „епохи“ (2012 начало, 2013–2020 сезони
октомври–октомври, 2021 преход към календарна година, днес). За всяка: година като голяма
цифра в акцентния цвят (похватът от класирането), 2–3 изречения, една снимка. Ако искаме
линия: вертикална `border-left` с точки (`::before`), без scroll анимация. Нужни са 5–6 добри
снимки общо, не 14.

## 2. Общо класиране

**Структура:**
- Hero 450 px със заглавие в центъра (име на серията + „Overall Ranking“).
- Ред с филтри, ~190 px под hero: **вляво** табове Men / Women / Team в общо „хапче“ (фон
  `#FAFAFA`, радиус 18 px; активният таб е с акцентен фон и бял текст, 14 px / 700, височина
  36 px); **вдясно** падащо меню за година (бяло, контур 1 px акцент, 154×48 px, 18 px / 600).
- Списъкът е в заоблена карта (`#FAFAFA`). Не е `<table>`, а редове с CSS grid:
  `grid-template-columns: 110px auto 200px 106px 106px` (място, име, отбор, държава, точки).
- Ред: височина ~47 px, само долна линия 1 px, без зебра. Мястото е **голяма акцентна цифра**
  (Ubuntu 700, ~30 px, с „º“). Името е с главни букви, 14–16 px / 600. Заглавният ред е сив,
  14 px, без фон.
- Първите 10 реда, после черен бутон „Load more results“ в центъра.
- Няма снимки на атлети, няма подиум, няма hover ефект на редовете.

На телефон: grid-ът се свива до `110px auto 106px`; останалите колони се достигат с
хоризонтално плъзгане вътре в картата. Филтрите остават на един ред.

**1:1:** подредбата на филтрите (табове вляво, сезон вдясно на един ред), голямата акцентна
цифра за мястото, картата със заоблени ъгли, редове само с долна линия.
**Адаптация:** запазваме нашия подиум за топ 3 (по-силен от GTWS) и „Покажи всички“ вместо
„Load more“ (работи без JavaScript). Колоните при нас са място, атлет, точки (+ подиуми за
сезоните, които ги имат); няма отбор и държава. На телефон нашата таблица вече се побира без
плъзгане, което е по-добре от GTWS. Конкретна промяна: местим падащото меню за сезон на реда
на табовете и правим цифрата на мястото по-голяма и акцентна.

## 3. Партньори

**Структура:**

- За всеки тиер: секционно h2 („Title partner“, „Official partner“) и **един блок на
  партньор** по схемата от About: лого (макс. височина 98 px; 39 px на телефон), абзац

- Сива лента на цяла ширина (`#D9D9D9`) „Do you want to be our next partner?“: заглавие и
  черен бутон вляво, текст вдясно (2 колони).
- Във футъра на всяка страница: лента „Our Partners“ с малки лога по тиер (grid 6 колони, 3 на
  таблет, 2 на телефон), всяко под малък сив надпис на тиера.

Йерархията между тиерите идва от **реда и заглавието**, не от размера: и двата партньора
получават еднакъв блок. Няма мрежа от много лога, защото партньорите са само трима.

**1:1:** лентата „Стани партньор“ с бутон; малката лента с лога във футъра на всички страници.
**Адаптация за `/partniori/`:** големият блок „лого + текст + снимка“ само за генералния
партньор (ако има такъв). Останалите в мрежа:

## 5. Начална страница

**Hero:** блок с височина ~687 px (съотношение 1920/925, макс. 80% от височината на екрана),
снимка `cover`, заоблени долни ъгли 64 px. Върху снимката, долу вляво, **светла
полупрозрачна карта** (бяло ~80%, радиус ~18 px, ширина ~1060 px) с h1 48 px в тъмен цвят и
акцентен бутон. Прозрачният хедър е върху снимката. Следващата секция започва 48 px под hero.

**Ред на секциите:**
1. Hero с последната новина.
2. Три новини в ред (снимка 432×310 с радиус 18 px, етикет + дата, заглавие 24 px на 2 реда,
   „Read more“), под тях черен бутон „More news“.
3. „Series“: списък на състезанията като **редове**, не карти: малка снимка, име + подзаглавие,
   дата, знаме, бутон „View Race“; всеки ред е отделна светла лента с радиус, gap 12 px.
4. Хоризонтален ред от високи карти (250×557) със scroll-snap, за националните серии.
5. Видео секция: плейър вляво, списък с епизоди вдясно, падащо меню за година.
6. Бюлетин (2 колони: текст и форма вляво, снимка вдясно).
7. Лента с партньори, после черен футър с голямо лого и 4 колони връзки.

            border-radius: 0 0 64px 64px; }

на дъното на hero, запълнен с цвета на следващата секция. Нашият hero вече има такъв планински
силует, така че това е въпрос на избор между двете форми, не на нова техника.

**1:1:** заоблените долни ъгли на hero, новините веднага под него, списъкът със състезания

## Какво не е проверено

- Hover състоянията са изведени от CSS класовете, не са гледани на живо.
- Страниците на отделно състезание, новина и „Top 30“ не са разглеждани.
- Дали Geist има пълна кирилица не е проверявано; не е нужно, защото запазваме нашите шрифтове.
